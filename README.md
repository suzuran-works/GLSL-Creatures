# GLSL-Creatures
Phaser/GLSLで生き物の模様を描くプロジェクト

# Phaser
- [Phaser](https://phaser.io)はHTML5用ブラウザゲームライブラリです。

# Font
- スマートフォントUI
  - フロップデザイン様 https://www.flopdesign.com/

# Development
- shadersフォルダにシェーダーを配置すると自動的に読み込まれて表示されます。
- ローカル環境での実行 `npm run dev`
